      How this was built

      1. Raw data 6,150 order rows with real-world problems: duplicates, three date formats, 'Bangalore' vs 'BENGALURU', prices stored as '₹1,299.00', missing values and impossible dates.
      2. Cleaning in Python (Pandas) Each step is logged with row counts. 209 bad rows removed; regions recovered from city; delivery time and SLA breach calculated.
      3. Analysis in SQL 12 queries in SQLite using GROUP BY, CTEs and window functions (RANK, ROW_NUMBER) for courier, category, city, payment and seasonality views.
      4. Dashboard This page. Plain HTML and Chart.js; all filtering happens in the browser.

      Data is synthetic, generated by a fixed-seed script to look like a real order export. Numbers are for demonstration only.
